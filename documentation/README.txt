# RAG Package - Universal AI IDE Integration

## What's Inside

This package contains a complete RAG (Retrieval-Augmented Generation) system
ready for use with ANY AI coding assistant.

### Directory Structure

```

├── vectors/
```

## Technical Details

- **Embedding Model**: all-MiniLM-L6-v2 (384 dimensions)
- **Chunk Size**: 512 tokens with 25% overlap
- **Search**: Hybrid (Vector + BM25 keyword)
- **Reranking**: Cross-encoder for precision
- **Knowledge Graph**: spaCy NER extraction

## Processing Stack (100% Open Source)

- sentence-transformers (embeddings)
- FAISS (vector search)
- spaCy (NER)
- BM25 (keyword search)
- NetworkX (knowledge graphs)

No paid APIs were used. All processing runs locally.
