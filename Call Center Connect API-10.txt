API for initiating outbound calls.

General description

The Call Center Connect (CCC) API enables seamless call initiation directly from external applications
such as CRMs and other business platforms. This short guide provides an overview of the key
endpoints and core functionality, helping you quickly integrate and start making calls through the CCC
system.

Getting Started

Once the feature is enabled for your organization, the Org Admin can generate an API key by navigating
to the My Company section and opening the API KEYS tab.

API Key Generation

To begin using the CCC API, you'll need an integration API key. This key is generated once for your
organization (Contact Support team for that) and can be shared with team members who require
access. The API key must be included in the header of every request made to the CCC server to ensure
proper authentication and access to the platform.

Voice Message Call

AUTHORIZATIONS: bearerAuth

REQUEST BODY SCHEMA: application/json



required

phone string
required The phone number to call.

clip_url string
required The URL of the audio/video file to play during the call. Supported formats:

Audio: MP3, WAV, AAC
Video: MP4, AVI, MOV (audio track extracted)

webhook string

The webhook URL for sending DTMF choices

caller_id string

Phone number from which the call originates. If provided, the system verifies
whether it matches a DID number assigned to the organization.

tag string

Some additional information to use with a webhook.

Responses

201 Call successfully created

400 Invalid request

500 Internal server error

Callbacks

POST DTMF alert

Notify the registered URL with details of DTMF.
